# E_commerce_Shipping_Analysis_using_SQL

**Situation:**
In this project, i worked on E commerce shipping database with around 11000 orders. The company was facing challenges with frequent shipment delays and inconsistent which 
factors such as warehouse, shipping mode or discount were affecting performance.
**Task**
my main task was to analyze this data to find key pattern and performance bottlenecks. Specifially i needed to identify reasons for delays deliveries,compare warehouse 
performance and suggest improvement to reduce delays and improve customer satisfaction.
**Action**
I used SQL to explore and analyze the data.I run aggregation quiries to find delay percentage, average discounts, warehouse performance and shipment mode efficiency.
**Result**
1. Around 60% of orders were delayed, especially from warehouse B and via flight shipments.
2. Heavy products and higher Discount were more likely to be delayed
3. Warehouse D had the best customer ratings,indicating better efficiency.
4. these insight could help the company optimize warehouse operations, adjust shipping strategies and manage discount smarter.

   **overall, the project improved understanding of operational bottelnecks and provided data driven recommendations to improve on-time delivery performance**
